    Class QuantizationTimerQueue<T>

    A queue of items of type T that coalesces bursts of enqueued items into batches, raising a single notification once no new items have arrived for a configured idle delay (subject to a minimum interval between notifications).

    Remarks

    Each call to Enqueue(T) adds an item to the queue and (re)starts the idle delay before the next notification is raised. Once no new items have been enqueued for the idle delay period, all items accumulated during that window are delivered together as a single batch, rather than triggering one notification per item.

    This is useful for reducing the overhead of processing discrete items (e.g. log entries, notifications, or queued commands) one at a time, by instead handling them together as a batch once activity has settled down.
