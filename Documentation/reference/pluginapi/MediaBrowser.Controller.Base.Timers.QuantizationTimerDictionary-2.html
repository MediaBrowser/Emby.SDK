    Class QuantizationTimerDictionary<TKey, TValue>

    A dictionary of key/value pairs of types TKey and TValue that coalesces bursts of added or updated entries into batches, raising a single notification once no new changes have arrived for a configured idle delay (subject to a minimum interval between notifications).

    Remarks

    Each call that adds, updates or removes an entry (re)starts the idle delay before the next notification is raised. Once no new changes have occurred for the idle delay period, the accumulated dictionary is delivered as a single batch, rather than triggering one notification per change.

    This is useful for reducing the overhead of processing discrete changes (e.g. log entries, notifications, or queued commands) one at a time, by instead handling them together as a batch once activity has settled down.

    System.TimeSpan minInterval

    The minimum amount of time that must pass between two consecutive batch notifications.
    System.Boolean executionTimeAddsToInterval

    If set to true, the time spent executing the notification handler is included when computing minInterval; otherwise the interval is measured independently of execution time.
