    Class PropertyOptionValue

    One property value which differs from its baseline, identified by its path within the options object and carried as an invariant-culture string.

    Remarks

    The value is deliberately not typed: the target property is the authority on its own type, so OptionValueManager converts back through that property's System.ComponentModel.TypeConverter when applying. That keeps no type names in the persisted form - renaming or moving a type cannot invalidate stored values - and avoids the guesswork an object member would need on deserialization. A null Value means the property was set to null (or, for strings, cleared); the presence of the entry itself is what distinguishes that from "not set".

    Properties

    PropertyPath

    Gets or sets the dot-separated path of the property within the options object, not including the object's own type name (so renaming the options class does not invalidate it). Items of an IEditableObjectCollection appear as a colitem<index> segment, matching the editor ids built by EditorBuilder.
