    Class QuantizationTimerList<T>

    A list of items of type T that coalesces bursts of added items into batches, raising a single notification once no new items have arrived for a configured idle delay (subject to a minimum interval between notifications).

    Remarks

    Each call to Add(T), AddRange(IEnumerable<T>), Remove(T) or Clear() modifies the list and (re)starts the idle delay before the next notification is raised. Once no new modifications have occurred for the idle delay period, the accumulated list is delivered as a single batch, rather than triggering one notification per change.

    This is useful for reducing the overhead of processing discrete items (e.g. log entries, notifications, or queued commands) one at a time, by instead handling them together as a batch once activity has settled down.
