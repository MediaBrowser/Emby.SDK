    Class IdleTimer

    A timer that tracks transitions between Busy, Idle and Suspended states based on activity signals and configurable timeouts.

    Inheritance
    System.Object
    IdleTimer
    Implements
    System.IDisposable
    Namespace: MediaBrowser.Controller.Base.Timers
    Assembly: MediaBrowser.Controller.dll
    Syntax
    public class IdleTimer : IDisposable
    Remarks

    The timer starts in the Suspended state. Calling code can request a transition to Busy to indicate active work, after which the timer will automatically transition to Idle after BusyTimeout elapses (if set), and subsequently to Suspended after IdleTimeout elapses (if set). Consumers can await the TransitionToBusy, TransitionToIdle and TransitionToSuspended tasks to be notified when the respective state is reached, or subscribe to the StateChanged event.

    Parameters
    Type Name Description
    System.Nullable<System.TimeSpan> busyTimeout

    The busy timeout. A 'null' value means that no timed transition is performed. A value of System.TimeSpan.Zero is not allowed and will throw an System.ArgumentOutOfRangeException.
    System.Nullable<System.TimeSpan> idleTimeout

    The idle timeout. System.TimeSpan.Zero means immediate transition from idle to suspended. A 'null' value means that no timed transition is performed.

    SetBusy()

    Sets the state to Busy.

    Declaration
    public void SetBusy()
    Remarks

    When setting states manually, timeouts of System.TimeSpan.Zero are ignored. In this case, when setting the state to Busy and the BusyTimeout is set to System.TimeSpan.Zero, the state is not transitioned to Idle. When the BusyTimeout is set to a non-zero value, the timer is reset, so the timeout period is restarted.

    SetIdle()

    Sets the state to Idle.

    Remarks

    When setting states manually, timeouts of System.TimeSpan.Zero are ignored. In this case, when setting the state to Idle and the IdleTimeout is set to System.TimeSpan.Zero, the state is not transitioned to Suspended. When the IdleTimeout is set to a non-zero value, the timer is reset, so the timeout period is restarted.
