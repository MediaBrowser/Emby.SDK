    Enum SelectItemsHelpMode

    Controls how a select item's description (EditorSelectOption.Description) is surfaced to the user, in addition to the property's own normal, static description.

    Namespace: MediaBrowser.Model.Attributes
    Assembly: MediaBrowser.Model.dll
    Syntax
    public enum SelectItemsHelpMode

    Fields

    Name Description
    DescriptionAdd

    Whenever an item with a description is selected, its text is appended below the field's own static description (both are shown together).
    DescriptionReplace

    Whenever an item with a description is selected, its text replaces the field's own static description (falls back to the static description while no such item, or one without a description, is selected).
    HelpDialog

    The field's own static description is left untouched and no per-item description is shown inline; instead, a help button is added next to the dropdown. Clicking it opens a dialog listing every item's value, name, and description in a table.
    HelpDialogHideValues

    Same as HelpDialog, except the value column is omitted from the dialog's table (only name and description are shown) - useful when the raw values are internal/technical and not meaningful to the user.
    None

    Item descriptions are ignored - the field behaves exactly as it would without any of them being set.
